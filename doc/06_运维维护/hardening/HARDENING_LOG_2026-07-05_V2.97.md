## V2.97 —— 最小顶点覆盖（König 精确算法 + 贪心 2-近似算法）

### 功能摘要

新增 `gos_runtime::graph_vertex_cover<N>()`——求解存活内核图的最小顶点覆盖 τ(G)。

**顶点覆盖**是指一组节点 T，使得每条边 (u,v) 至少有一个端点在 T 中。
最小顶点覆盖（min-VC）是满足此条件的最小集合。

**双路径算法：**
- **二分图：** 通过 König 定理求得精确最小顶点覆盖。运行 BFS 二着色 +
  Kuhn 增广路径匹配 + 交替路径 BFS（König 构造法）。精确返回 τ(G) = ν(G)。
- **一般（非二分）图：** 通过贪心极大匹配求得 2-近似解。对每条未覆盖的边
  (u,v)，将两个端点都加入覆盖集合。保证：cover_size ≤ 2 × τ(G)。

### API

```rust
pub fn graph_vertex_cover<N: usize>() -> ([VectorAddress; N], usize, bool, usize)
// 返回：(cover_vecs, cover_size, is_exact, node_count)
//   cover_vecs[0..cover_size] —— 覆盖集合中的顶点，按 as_u64() 升序排序
//   cover_size                —— |最小顶点覆盖|；二分图为精确值，一般图 ≤2倍
//   is_exact                  —— 当且仅当为二分图（König 算法）时为 true
//   node_count                —— 存活节点总数
```

### König 构造法（二分图情形）

1. BFS 二着色 → 划分为 A（颜色=0）与 B（颜色=1）
2. Kuhn 增广路径 DFS → 最大匹配 M，数组 `match_a[]`、`match_b[]`
3. 从未匹配的 A 节点出发进行 König BFS：
   - A 节点属于 Z → 沿所有非匹配边前往 B 侧（b ≠ match_a[a]）
   - B 节点属于 Z → 沿匹配边前往 A 侧（a = match_b[b]）
4. 覆盖集合 T = **(A \ Z_A) ∪ (B ∩ Z_B)**

**证明梗概：** T 覆盖所有边，因为对任意边 a-b：
- 若 b ∉ Z_B：则 b 从未被到达 → 为使 M 最大，a 必然属于 A\Z_A（在 T 中）
- 若 b ∈ Z_B：则 b 直接属于 T

### 操作系统类比

内核模块的最小集合，使得每一次 IPC 通道通信、系统调用或驱动交互都
至少经过其中一个模块——这是系统依赖图中对所有跨模块通信进行审计的
最小"检查点"集合。

类似于网络中必须被监控以观察所有流量的最小节点集合（最小监控集合 /
流量拦截覆盖）。

### 算法复杂度

- 二分图：O(V·E) —— Kuhn 匹配 + O(V+E) König BFS
- 一般图：O(E) —— 贪心极大匹配扫描
- 空间：内核栈上 O(V) 额外数组（约 10 KB 总计）

### 参考文献

- König 1931："Graphen und Matrizen"，通过最大匹配求二分图精确最小顶点覆盖
- Gallai 1959：α(G) + τ(G) = n（独立数与覆盖数的互补关系）
- Kuhn 1955 / 匈牙利方法：增广路径二分图匹配
- Garey & Johnson 1979：一般图上最小顶点覆盖为 NP 完全问题（Karp 归约 6）
- Bar-Yehuda & Even 1981：基于极大匹配的 2-近似算法
