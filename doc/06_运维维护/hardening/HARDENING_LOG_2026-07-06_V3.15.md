## V3.15 — Sombor + 约化第二 Zagreb + Sigma 基于度数的拓扑指数

### 新增运行时 API

```rust
pub fn graph_topo_indices4() -> (u64, u64, u64, usize, usize)
// 返回值：(so_ppm, rm2, sigma, edge_count, node_count)
```

### 新增指数

| 符号 | 名称 | 公式 | 参考文献 |
|--------|------|---------|-----------|
| SO | Sombor 指数 | Σ_{uv∈E} √(da²+db²) | Gutman 2021 |
| RM₂ | 约化第二 Zagreb 指数 | Σ_{uv∈E} (da-1)·(db-1) | Furtula, Gutman & Ediz 2014 |
| σ | Sigma 指数 | Σ_{uv∈E} (da-db)² | Gutman et al. 2014 |

### 整数精度

- **SO**：`so_ppm = Σ isqrt64((da²+db²) × 10^12)` — 牛顿-拉夫逊向下取整平方根；每条边误差 ≤ 1 ppm
- **RM₂**：精确整数；`(da-1)·(db-1)`；对悬挂边（da=1 或 db=1）为 0
- **σ**：精确整数；`(da-db)²`；恒非负；当且仅当图为正则图时为 0

### 关键不变量

**SO：**
- 对 Δ-正则图，SO = |E|·da·√2（向下取整；仅当 2Δ² 为完全平方数时精确——对 Δ≥1 永不成立）
- SO 单调：增加边数或提高度数总会使 SO 增大

**RM₂：**
- 对任意悬挂边端点（da=1 或 db=1），RM₂ = 0 → 星形图恒有 RM₂=0
- 对任意 Δ-正则图，RM₂ = |E|·(Δ-1)²（精确整数）
- K₃（Δ=2，3 条边）：RM₂ = 3·1² = 3（精确）
- K₄（Δ=3，6 条边）：RM₂ = 6·2² = 24（精确）

**σ（Sigma 指数）：**
- **当且仅当图为正则图**时 σ = 0 —— 严格的正则性证明
- 当 σ=0 且 edge_count>0 时，shell 会显示标注（确认正则性）
- σ = Σ (da-db)² ≥ 0 恒成立；对 K₃、K₄、Kₙ、Cₙ、正则网格均为 0

### 算法（O(V+E)）

与 V3.12–V3.14 相同的紧凑索引 + 无向邻接位掩码构建方式。
按 `a < b` 规范顺序进行边扫描：

```rust
// SO: isqrt64((da²+db²) × 10^12)
so_acc += isqrt64((da * da + db * db) * 1_000_000_000_000u64);

// RM₂: (da-1)·(db-1)；悬挂边贡献 0
if da > 0 && db > 0 {
    rm2_acc += (da - 1) * (db - 1);
}

// σ: (da-db)²；对正则图为 0
let diff = if da >= db { da - db } else { db - da };
sigma_acc += diff * diff;
```

溢出安全性：
- SO：最大 `da²+db² ≤ 2·128² = 32_768`；`32_768×10^12 = 3.28×10^16` — 可容纳于 u64（上限约 1.8×10^19）✓
- RM₂：每边最大 `(127)·(127) = 16_129`；总计最大 `512×16_129 ≈ 8.3×10^6` — 轻松容纳于 u64 ✓
- σ：每边最大 `(128-1)² = 16_129`；总计最大约 8.3×10^6 — 轻松容纳于 u64 ✓

### 操作系统类比

- **SO** = (da, db) 端点度数对的欧几里得范数——SO 越高表示中枢-辐射不对称性越大；
  对均匀网状（正则）拓扑，SO = |E|·Δ·√2
- **RM₂** = "内部耦合密度"——超出度数 1 之外的连接数之积；
  对所有星形拓扑边为 0；对环状/网状（正则）拓扑等于 |E|·(Δ-1)²
- **σ** = IPC 通道间总度数不平衡的平方和——σ=0 证明内核依赖图完全均衡（正则）；
  σ 越高表示越以中枢为主导、故障越不对称的拓扑
